## Overview

- **Repo:** nihanthnaidu007/ai-stamp — `ai-stamp` v0.1.0 (MIT), Alpha
- **What it is:** Python library + CLI for AI-output provenance and compliance: wraps LLM calls (OpenAI / Anthropic / generic HTTP / Python callable), hashes prompts+responses, HMAC-signs provenance records, detects PII, evaluates warn/block policy rules, and stores records in SQLite or PostgreSQL. Exports audit reports as JSON/CSV.
- **dev_stack_healthy: true** (validated 2026-09-17)
